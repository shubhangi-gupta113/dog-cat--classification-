# Dog vs Cat Image Classification

This project builds a Convolutional Neural Network (CNN) model using TensorFlow/Keras to classify images of dogs and cats.

##  Project Overview
- **Task:  Binary Image Classification (Dog vs Cat)
- **Framework:  TensorFlow / Keras / Python
- **Environment:  Google Colab

##  Dataset
The dataset contains images of dogs and cats resized and normalized for training.

##  Model Architecture
- Convolutional Layers (Conv2D + MaxPooling2D)
- Dropout layers for overfitting reduction
- Dense layers with ReLU and Sigmoid activation functions

##  How to Run
1. Clone this repository or open the `.ipynb` file directly in Google Colab.
2. Run all notebook cells sequentially to train and evaluate the model.
